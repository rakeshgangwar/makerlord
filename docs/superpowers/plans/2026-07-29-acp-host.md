# MakerLord ACP Host Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `maker-bridge` — the local daemon that spawns external agent binaries over ACP, scopes each to one project via a per-session MCP server, and normalises everything into the one `SessionEvent` stream the UI renders.

**Architecture:** Two packages. `@makerlord/protocol` owns the `SessionEvent` union — the only shape the UI ever renders, consumed by bridge, agent runtime and UI alike. `@makerlord/bridge` owns the agent registry with PATH probing, the newline-delimited JSON-RPC 2.0 client, the ACP session lifecycle, event normalisation, and the localhost transport with origin pinning and pairing.

**Tech Stack:** TypeScript (strict), Node 22, pnpm, Vitest, ws.

**Prerequisite:** the tool surface (the per-session MCP server the bridge hands out is `maker-mcp`, launched scoped).

**Spec:** [../specs/2026-07-29-acp-host-design.md](../specs/2026-07-29-acp-host-design.md)

## Global Constraints

- **No MCP capability → refuse the agent** with a message naming the missing capability and offering the hosted agent. A toolless agent can only produce prose about a circuit it cannot see (D2).
- **`initialize` times out at 10 s** (configurable for tests). A binary that does not handshake is broken or not an ACP agent.
- **The agent gets one project's authority and nothing more:** no tokens, no repo URLs — just `maker-bridge mcp --session <opaque id>`.
- **Stderr is ring-buffered and surfaced, never discarded.** Mid-turn exit emits `session.error` with exit code + last 4 KiB of stderr.
- **The bridge auto-approves nothing.** Permission requests surface as `permission.ask`.
- **Refusals stay refusals** — `tool.end` carries `ToolResult` verbatim to the renderer.
- **Kill discipline:** SIGTERM, then SIGKILL after 5 s. Bridge shutdown leaves no orphans.
- **Protocol drift is absorbed in `normalize.ts`**, nowhere else.

## File Structure

```
packages/protocol/src/events.ts    SessionEvent, PermissionOption, PlanStep, StopReason
packages/bridge/src/
├── registry.ts                    AgentEntry, builtin probes, agents.json, probe()
├── rpc.ts                         ndjson JSON-RPC 2.0 over child stdio
├── acp.ts                         spawn → initialize → session/new → prompt; kill
├── normalize.ts                   ACP session/update → SessionEvent
├── sessions.ts                    opaque session id → project path
├── pairing.ts                     origin pinning + pairing tokens
└── index.ts
packages/bridge/test/fake-agent.mjs   scripted ACP agent, real subprocess
```
