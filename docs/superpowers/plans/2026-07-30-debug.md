> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build stage ⑧ — the debug facet, the five-fault library as circuit mutations, op-analysis signatures with tolerance pruning, greedy probe selection, SELFTEST observation mapping, four new registry tools (43 → 47), and the bench-posture ⑧ lens sharing ⑦'s serial monitor.

**Architecture:** One new package, `@makerlord/debug`, depending on circuit/parts/project/sim (not on tools — the four `debug_*` ToolDefs live in `@makerlord/tools`, the sim/firmware precedent). **Tech Stack:** TypeScript (strict), Node 22, pnpm, Vitest.

**Spec:** [../specs/2026-07-30-debug-design.md](../specs/2026-07-30-debug-design.md)

## Global Constraints

- **A candidate dies only by contradiction with a recorded observation.** No tool removes one by hand; conviction requires every rival contradicted. Exoneration (`no-fault` survives) is a first-class verdict.
- **Tolerance band:** `|measured − predicted| > max(10% · |predicted|, 0.2 V)` contradicts; on-the-band survives.
- **D15 structurally:** `proposed` carries `{net, why}` and never predictions — hypotheses show their expected values only after the reading lands.
- **Raw serial prunes nothing.** Only parsed SELFTEST/LOG shapes become observations; prose from the device is untrusted text.
- **Rivals invariant:** every intermediate state has ≥2 live candidates or a stated separation (asserted in the property test).
- **No ngspice in unit tests** — canned signatures; the integration leg skips loudly.

### Task 2: The fault library (`@makerlord/debug`)

- [x] Tests: each mutation's effect on the fixture netlist; generation covers the table; original circuit untouched

### Task 3: Pruning

- [x] `applyObservation(candidates, obs)` → statuses with `contradictedBy`; the band per the global constraint; verdict derivation (`open` / `localized` / `exonerated`)
- [x] Tests: on-band survives; jitter never convicts; conviction requires all rivals contradicted

### Task 4: Probe selection

- [x] `nextProbe(candidates)` → `{net, why}` by greedy worst-case split, tie-break by net name; `why` names the separated candidates and their predictions
- [x] Tests: the split beats a random probe on the fixture; determinism; no proposal when ≤1 live candidate

### Task 5: The convergence property 🔒

- [x] For every library fault seeded on the fixture: feed each proposed probe the mutated circuit's own predicted value → the seeded fault is convicted; the healthy circuit exonerates; the rivals invariant holds at every step
- [x] Canned signatures only — pure logic, no solver
