# MakerLord Go-Live Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take the hosted path live on `infra` (178.105.68.68) at **makerlord.dev**: streaming transport in the agent, the hosted server exposing sessions over SSE with replay, the SvelteKit UI served behind Caddy, and a live smoke test against the real API.

**Prerequisites (met 2026-07-29):** `ANTHROPIC_API_KEY` in `.env`; `makerlord.dev → A 178.105.68.68` resolving; server surveyed idle (docs/infra.md).

**Unblocks (deferred-work.md §A):** streaming transport, SSE/WS live wiring, compaction-beta pass-through, web-research config.

## Global Constraints

- **One event consumer stays one:** SSE delivers the same `SessionEvent` union; reconnection replays from `Last-Event-ID` (UI spec §10).
- **Streaming is transport, not semantics:** deltas arrive earlier; the union is unchanged; the fake LLM speaks real SSE so tests cover the streaming path, not a mock of it.
- **`.env` never leaves the machines it belongs to** — scp'd to `/opt/makerlord/.env`, never committed, never in an image.
- **`.dev` is HSTS-preloaded** — Caddy terminates TLS from the first request.
- **The server holds one project per session** and exposes no filesystem beyond the projects root.
